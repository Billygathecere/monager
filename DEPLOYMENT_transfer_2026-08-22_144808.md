# GAP//FLOW v3.1

Upload the entire folder to an HTTPS static host. Keep `icons/icon.svg`, `manifest.webmanifest`, `sw.js`, and `index.html` together. Open the HTTPS URL in Chrome on Android and choose Install App / Add to Home screen.

The tracker stores financial records locally in the browser. Exact background push notifications require a deployed notification service; the current 25th reminder is an in-app/browser-permission feature.
